## Work Completed

### 1. Root Cause Analysis
- **Problem:** BenchmarkDotNet temp project generated inside `bin\Release\net10.0\` inherits repo-root `Directory.Build.props`
- **Effect:** Output paths redirect to `BuildOutput\obj\Release\BenchmarkDotNet.Autogenerated\`, but NuGet restore wrote `project.assets.json` to default SDK path
- **Error:** `NETSDK1004: Assets file not found`

### 2. Fix Applied
- **File created:** `Sage_Aux\SageBenchmarks\Directory.Build.props`
- **Strategy:** Chain parent props (preserve shared settings) + reset all output-path properties to empty
- **Result:** Both `SageBenchmarks.csproj` and BDN temp project use standard SDK layout; `project.assets.json` in expected location
