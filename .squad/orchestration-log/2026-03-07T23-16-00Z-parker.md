## Technical Decisions

### Heterogeneous Stacks
For stacks containing mixed types (e.g., dependency graph traversal with multiple vertex types), used `Stack<object>` pattern:
- **DagCycleChecker.cs** — `Stack<object>` for path nodes of different vertex types
- **ICreationContext.ParentObjectStack** — `Stack<object>` for parent chain of mixed object types

### Name Collision Avoidance
**ItemBased.Queue.cs** implements a non-generic `Queue` class in the ItemBased.Queues namespace. In **TestPfcNetworks.cs**, used fully-qualified generic queue to disambiguate:
```csharp
// Instead of: Queue<IPfcNode> queue;
// Used: System.Collections.Generic.Queue<IPfcNode> queue;
```

### Preserved Non-Generics
Per Phase 2 specification, did NOT modify:
- `object userData` fields (user-defined data, intentionally untyped)
- `IDictionary graphContext` (legacy context pattern)
- `WeakHashTable` (utilities, internal use only)
