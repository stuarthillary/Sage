## Key Findings

### Highest-Risk Gap: CausalityException

`Executive.RequestEvent` throws `CausalityException` when `when < _now` and `IgnoreCausalityViolations = false`. **Zero test coverage.** A regression here silently allows simulations to process events out of order, producing wrong results with no error signal.

### Cross-Test Contamination Risk

Static fields `_clrConfigDone` and `_ignoreCausalityViolations` in Executive are modified by instance constructors. Tests running in parallel can mutate each other's causality enforcement setting.
